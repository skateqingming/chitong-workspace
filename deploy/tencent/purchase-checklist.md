# 腾讯云购买页选择清单

只做企业管理系统和未来 App 后端时，按这份选。

## 购买产品

```text
轻量应用服务器
```

## 推荐配置

```text
地域：中国香港
系统镜像：Ubuntu 22.04 LTS
套餐：2 核 4G
带宽：默认
购买时长：先 1 个月或 3 个月
登录方式：密码登录或 SSH 密钥登录
```

## 防火墙放行

```text
22   SSH 登录服务器
80   HTTP 临时访问
443  HTTPS 正式访问
```

## 先不要买

```text
云数据库
对象存储 COS
CDN
负载均衡
高防
企业邮箱
官网相关产品
```

## 买完后你需要记录

```text
公网 IP
服务器用户名
登录密码或 SSH 密钥
服务器地域
```

## 为什么暂时不用备案

你选的是中国香港地域，第一阶段用公网 IP 或香港服务器绑定域名访问，通常不需要 ICP 备案。

如果以后换成中国大陆地域，并且绑定域名给员工公网访问，再做 ICP 备案。
