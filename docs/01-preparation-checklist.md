# 内部 APP 准备清单

## 业务准备

- 明确第一个核心场景：先做一个高频痛点，不要一开始做“全公司宇宙飞船”。
- 梳理用户角色：管理员、主管、员工、财务、人事、访客等。
- 定义关键流程：提交、审批、驳回、归档、导出、通知。
- 准备字段清单：每个表单需要哪些字段，哪些必填，哪些敏感。
- 确认数据来源：手工录入、Excel 导入、ERP/CRM/财务系统同步。
- 明确成功指标：节省多少时间、减少多少错误、提升多少可见性。

## 技术准备

- 身份登录：企业微信、飞书、钉钉、Microsoft Entra ID 或自建账号。
- 权限模型：RBAC 角色权限是默认起点，复杂组织再升级 ABAC。
- 数据库：建议 PostgreSQL；小型内网工具可先 SQLite。
- 文件存储：合同、发票、附件建议放对象存储，不要塞进数据库。
- 部署环境：内网服务器、云服务器、容器平台或 Serverless。
- 备份恢复：至少每日备份，关键系统需要恢复演练。

## 合规与安全

- 确认哪些数据属于个人信息、财务信息、商业秘密。
- 所有关键操作必须有审计日志。
- 后台管理必须有最小权限原则。
- 生产环境必须使用 HTTPS。
- 敏感配置必须放环境变量或密钥管理系统。
- 离职员工账号要能自动禁用。
