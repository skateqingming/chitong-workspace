# 安全清单

## 必做

- 密码不能明文保存；当前原型为了演示才写在 JSON 中。
- 登录态必须有过期时间和刷新机制。
- 后端必须校验权限，不能只靠前端隐藏按钮。
- 所有输入都要校验长度、类型和格式。
- 所有写操作都要记录审计日志。
- 生产数据库必须定期备份。
- 管理员操作需要二次确认或更高等级认证。

## 推荐

- 接入企业 SSO，减少单独维护密码的风险。
- 对敏感字段做字段级权限控制。
- 附件上传做类型、大小、病毒扫描限制。
- 对导出数据做水印或审计。
- 关键接口加速率限制。
- 日志不要记录密码、密钥、身份证号等敏感信息。

## 上线前验收

- 权限越权测试。
- 数据导出测试。
- 备份恢复测试。
- 异常场景测试。
- 移动端适配测试。
- 浏览器兼容测试。
